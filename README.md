# OpticDiff Homebrew Tap

Official [Homebrew](https://brew.sh) tap for tools by [OpticDiff](https://github.com/OpticDiff).

## Installation

Add this tap and install `code-reviewer`:

```bash
brew tap OpticDiff/tap
brew install OpticDiff/tap/code-reviewer
```

Or install directly in one step:

```bash
brew install OpticDiff/tap/code-reviewer
```

## Available Formulae

| Formula | Description | Version |
|---|---|---|
| [`code-reviewer`](https://github.com/OpticDiff/code-reviewer) | Fast, local-first AI code review CLI & pre-push hook for GitHub PRs and GitLab MRs. Multi-model consensus, Tree-sitter AST context, and SARIF export. | `v0.8.0` |

## Updates

To update installed formulae:

```bash
brew update
brew upgrade code-reviewer
```
